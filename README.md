# Дневники практики

Программа на Python для работы с файлами **«Представление на практику»** (.docx):

* читает все группы и таблицы студентов из представления (с учётом объединённых ячеек Word);
* показывает их в удобной таблице с поиском и фильтром по группе;
* позволяет редактировать любые поля, сведения о группе, добавлять и удалять студентов и сохранять
  изменения обратно в .docx (оформление, нумерация и объединения ячеек сохраняются);
* хранит **справочник руководителей по местам практики**: руководитель от профильной
  организации вписывается один раз на место и подставляется всем студентам этого места;
  справочник можно загрузить из Excel;
* создаёт **дневники практики** для отмеченных студентов по шаблону: в шаблоне заменяются
  все фрагменты, выделенные **жёлтым** цветом.

## Установка

```bash
py -m pip install -r requirements.txt
```

Нужен Python 3.10+ (https://www.python.org/downloads/, при установке отметьте
«Add python.exe to PATH»). На Linux/macOS вместо `py` используйте `python3`.

## Запуск графического интерфейса

```bash
py main.py
```

Можно сразу указать файл: `py main.py Представление.docx`.

1. **Открыть** — выбрать файл представления.
2. Слева — список групп и их сведения (код/название направления и профиля, форма обучения и т.д.).
   Эти поля можно править.
3. Справа — таблица студентов. Двойной щелчок по ячейке — редактирование.
   * Колонка **«Руководитель от организации»** берётся из справочника по месту практики
     (двойной щелчок по ней открывает справочник на нужном месте).
4. **Справочники → Руководители по местам практики** — список всех мест (из справочника и из
   открытого представления) и количество студентов на каждом. Впишите руководителя в строке
   места — изменения сохраняются сразу. Кнопка **«Загрузить из Excel…»** добавляет места и
   руководителей из присланной таблицы (нужны столбцы «Место …» и «Руководитель»); названия
   сопоставляются с учётом разных кавычек, пробелов и порядка слов. Фильтр «Только без
   руководителя» показывает, что ещё осталось заполнить.

   Справочник хранится в `%APPDATA%\practice_diary\places.json` (Windows) или
   `~/.config/practice_diary/places.json`, поэтому он общий для всех представлений.
5. **Сохранить** / **Сохранить как…** — запись изменений в .docx.
6. Отметьте галочками студентов (или «Отметить видимых» после поиска/выбора группы) и нажмите
   **«Создать дневники для отмеченных»**. В диалоге можно выбрать шаблон, папку и шаблон имени
   файла; там же видно, у кого не указан руководитель от организации.

## Что подставляется в дневник

| Жёлтое поле шаблона | Значение |
|---|---|
| Фамилия / Имя, отчество | из ФИО |
| Группа | из строки «Факультет, кафедра, группа» |
| Направление / Профиль | код + название из шапки группы |
| Место прохождения практики | колонка «Место» |
| Период практики | «03.12.2024 г. по 30.12.2024 г.» из колонки «Период реализации» |
| Руководитель от университета | колонка «Руководитель…» (в подписи — «Л.Н. Майорова») |
| Руководитель от профильной организации | из справочника по месту практики (в подписи — «Е.А. Новикова») |
| Сроки в рабочем графике | рассчитываются из периода (пропорционально образцу) |
| Отзыв | «Михайлец А.Ю.», место практики |

Дополнительно в тексте отзыва автоматически согласуется род по отчеству
(«Студент … прошел …» / «Студентка … прошла …»), это можно отключить.

Если в шаблоне есть жёлтое поле, которое программа не распознала, оно останется без изменений,
а программа сообщит об этом. Поля без данных заполняются чертой `____________________`.

Свой шаблон: любой .docx, в котором заменяемые значения выделены жёлтым маркером, а подписи
полей («Фамилия», «Группа», «Период практики», …) такие же, как в `templates/diary_template.docx`.

## Командная строка

```bash
python -m practice_diary.cli show Представление.docx --full
```

```bash
python -m practice_diary.cli places import Руководители.xlsx
```

```bash
python -m practice_diary.cli places set "ИП Осадчий Э.А." "Осадчий Э.А."
```

```bash
python -m practice_diary.cli places list
```

```bash
python -m practice_diary.cli diary Представление.docx -s Михайлец -s Асеев -o Дневники
```

```bash
python -m practice_diary.cli diary Представление.docx --group МЕНОZ-631 -o Дневники
```

```bash
python -m practice_diary.cli set Представление.docx Михайлец place "ООО «Ромашка»"
```

## Структура

```
main.py                     запуск GUI
practice_diary/
  models.py                 Group / Student
  predstavlenie.py          чтение и сохранение представления
  diary.py                  генерация дневника по жёлтым полям шаблона
  places.py                 справочник «место → руководитель», импорт из Excel
  docx_utils.py             работа с XML Word (ячейки, объединения, выделение)
  gui.py                    интерфейс на PySide6
  cli.py                    командная строка
templates/diary_template.docx   шаблон дневника
```
